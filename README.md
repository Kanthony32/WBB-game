# Program Builder

A women's college basketball program sim that runs in the browser. Open `index.html`; there is no build step and no server.

- Real 2026-27 rosters (Big East, SEC, Big Ten, ACC, Big 12, A-10, Ivy, Pac-12) and made-up rosters for the American and the SoCon
- Historic starts from any recruiting class, 2015 to 2026, with real 2014-15 rosters for 64 programs
- Live match engine, recruiting decision model, bracketology, assistant-to-head-coach career mode

Player ratings and attributes are invented game values, not real metrics. Saves live in the browser (localStorage).
